两个区的职责

附件解析图片
类型pdf/word/excel/md/json/图片…仅图片
AI不调用多模态识别
提交立即等解析完

下载支持也支持

解析图片本身就是一张图，所以它同样能下载 —— 但它的主职责是「被读懂」。

提交按钮的状态机

  1. 就绪 无解析任务 → 可点
  2. 解析中 置灰，文案「解析中…」
  3. 完成 恢复可点
  4. 失败 仍可点，按普通附件保存

为什么失败也允许提交：图已经上传成功了，因为模型超时就让你整个表单白填，是更糟的体验。

点一下试试

两个区的虚线框都能点：

  1. 点附件区 → 加两个文件，按钮不受影响
  2. 点解析图片区 → 加一张图并自动开始解析
  3. 看按钮从「解析中…」回到可点，字段被回填

直接看某个状态

地址栏加参数即可跳到指定状态：

  1. ?demo=attach 只加附件，按钮照常
  2. ?demo=parsing 解析中，按钮置灰
  3. ?demo=failed 解析失败，仍可提交
  4. ?demo=done 解析完成，字段回填
  5. ?tab=task&demo=done 任务表单的回填效果
