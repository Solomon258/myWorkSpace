# 干净机验收清单（M9-T06）

交付物：`personal-workbench-v1.0.0-win.zip`（68MB，SHA256 见同目录 .sha256 文件）

目标：在三类真实 Windows 机器上验证「解压 → 双击启动 → 浏览器打开 → 首次配置」全流程。
每类机器一台即可，验收结果填到文末表格。任何一步失败，先按文末「失败时采集什么」收集信息。

---

## 机器 1：无 Java 的 Windows 10/11

要求：不装 Java、Maven、Node、MySQL（控制面板 → 程序和功能 里确认没有 Java）。

- [ ] 1. 把 ZIP 拷到机器上，解压到一个简单路径（如 `D:\apps\`）
- [ ] 2. 双击 `启动工作台.cmd`，窗口提示"正在启动"
- [ ] 3. 60 秒内浏览器自动打开 `http://localhost:18080`，出现「首次配置」页
- [ ] 4. 设置用户名（2-32 字）和密码（4-72 字），进入驾驶舱
- [ ] 5. 收集箱录入一条："明天下午3点约业务方对齐Q4需求评审" → 点「AI 整理」
- [ ] 6. 到「整理确认」确认生成 → 任务列表出现该任务且时间正确
- [ ] 7. 创建一条收藏（工作空间）、一条日程
- [ ] 8. 点顶栏「番茄钟」→ 开始专注 → 能听到提示音或看到标题闪烁（可将时长先改 1 分钟测试）
- [ ] 9. 双击 `停止工作台.cmd` → 再双击启动 → 之前录的数据全部还在
- [ ] 10. 设置页 →「立即备份」→ 备份列表出现新文件 → 随便改一条数据 →「恢复此备份」→ 数据回到备份时状态
- [ ] 11. 任务管理器看 java.exe 内存 ≤ 300MB

## 机器 2：已装其他 Java 版本的电脑

要求：机器上已装任意其他版本 Java（如 Java 11/17/21），`java -version` 能显示。

- [ ] 1. 记录 `java -version` 显示的版本号：____________
- [ ] 2. 按「机器 1」的第 1-10 步完整执行
- [ ] 3. 确认全程没有用到系统 Java：启动后任务管理器里 java.exe 的「命令行」列（需手动加列）应显示路径含 `personal-workbench\runtime\bin\java.exe`
- [ ] 4. 系统 Java 的 `java -version` 在验收前后不变

## 机器 3：中文用户名 + 中文路径

要求：Windows 用户名为中文（如 C:\Users\张三），解压路径也含中文（如 `D:\工具\个人工作台\`）。

- [ ] 1. 解压到 `D:\工具\个人工作台\`（或类似中文路径）
- [ ] 2. 按「机器 1」的第 1-10 步完整执行
- [ ] 3. 额外验证：设置页「立即备份」生成的备份文件名正常、恢复可用（中文路径下文件读写最易出问题）

## 失败时采集什么

1. `personal-workbench\logs\` 整个文件夹打包（stdout.log / stderr.log / workbench.log）
2. 启动窗口的文字截图（拍照也行）
3. 浏览器地址栏 + 页面截图
4. 若双击后窗口一闪而过：在该文件夹地址栏输入 `cmd` 回车，手动执行
   `runtime\bin\java.exe -jar app\workbench.jar`，把报错文字完整复制下来
